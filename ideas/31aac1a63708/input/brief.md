# Brief de ideacion

## Objetivo
- Numero de ideas: 100
- Genero / subgenero: Distópico / Young Adult
- Publico objetivo (edad, region): 18-25 años, global
- Idioma: Español
- Formato (novela, serie, coleccion): Novela
- Longitud objetivo (palabras): 80,000-100,000
- Nivel de riesgo creativo (bajo/medio/alto): Medio-Alto
- Nivel de originalidad (seguro/medio/experimental): Medio

## Requisitos
- Elementos obligatorios: Sociedad distópica, protagonista joven, conflicto contra el sistema
- Elementos deseados: Alto nivel de engagement, gancho fuerte, worldbuilding inmersivo, stakes personales y sociales
- Elementos prohibidos: Clichés YA obvios (triángulos amorosos forzados, chosen one sin matices), soluciones simplistas

## Referencias
- Comparables (libros, peliculas, juegos): Los Juegos del Hambre, Divergente
- Influencias esteticas: Sociedades post-apocalípticas, sistemas opresivos, competencias mortales, facciones/castas

## Parametros narrativos
- Tono: Tenso, urgente, emocionalmente intenso
- POV: Primera persona o tercera persona limitada
- Tiempo verbal: Presente o pasado
- Ambientacion temporal: Futuro distópico
- Ritmo: Rápido, con acción constante

## Entrega
- Numero de ideas y formato esperado: 100 idea cards en Markdown
