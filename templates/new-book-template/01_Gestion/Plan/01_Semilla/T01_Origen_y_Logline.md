# T01 Origen y logline

## Objetivo
Capturar la idea del libro de forma estable: un origen claro y una logline que sirva como “ancla” para todo el proyecto.

## Entradas
- [[01_Gestion/Plan/00_Preparacion/T02_Parametros_Libro|T02 Parámetros del libro]]

## Checklist
- [ ] Completar en `01_Gestion/Semilla.md` (secciones “Origen” y “Logline”):
  - [ ] Origen del proyecto (por qué este libro, por qué ahora):
    - [ ] Chispa inicial: ¿qué lo disparó? (una escena, una pregunta, una experiencia, una noticia, etc.)
    - [ ] Motivación: ¿por qué te importa escribirlo? (personal/profesional/curiosidad)
    - [ ] Promesa al lector: ¿qué se lleva al terminar? (en 1–2 líneas, alineado con T02)
    - [ ] Alcance: ¿qué incluye y qué NO incluye? (para evitar deriva de alcance)
  - [ ] Logline (1 frase) usando esta estructura:
    - [ ] Protagonista (rol + rasgo) + situación inicial (contexto mínimo)
    - [ ] Objetivo concreto (verbo de acción)
    - [ ] Fuerza opuesta (antagonista/sistema/amenaza interna/externa)
    - [ ] Estaca: qué se pierde si falla (y/o qué cambia si gana)
    - [ ] Opcional: marco (tiempo/lugar) si agrega claridad
- [ ] Escribir 2–3 variantes de logline y elegir una “versión 1”:
  - [ ] Variante A: más directa (máxima claridad)
  - [ ] Variante B: más emocional (sube la estaca)
  - [ ] Variante C: más específica (incluye marco o giro diferencial)
- [ ] Validación rápida (sin “chequear”, solo sentido común):
  - [ ] Se puede leer en voz alta sin explicar contexto adicional
  - [ ] No describe “tema”; describe “historia” (personaje + acción + conflicto)
  - [ ] El objetivo es medible (se puede saber si se logró)
  - [ ] No depende de nombres propios para funcionar (si se quitan, igual se entiende)

## Salidas (Definition of Done)
- “Origen” escrito en `01_Gestion/Semilla.md` con chispa + motivación + promesa + alcance.
- “Logline” asentada en `01_Gestion/Semilla.md` como versión 1, con 1–2 variantes alternativas guardadas debajo.
