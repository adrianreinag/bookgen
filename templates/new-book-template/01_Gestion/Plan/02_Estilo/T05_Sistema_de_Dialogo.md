# T05 Sistema de diálogo

## Objetivo
Fijar formato y reglas de diálogo para que la prosa sea consistente (claridad + subtexto + ritmo).

## Entradas
- [[01_Gestion/Plan/02_Estilo/T04_Protocolo_Deep_POV|T04 Protocolo Deep POV]]

## Checklist
- [ ] Completar en `01_Gestion/Estilo.md` (sección “Diálogo”):
  - [ ] Convención de formato (rayas/comillas) según estándar elegido y 3 ejemplos mínimos:
    - [ ] Diálogo simple
    - [ ] Diálogo + acotación
    - [ ] Interrupción / pausa / énfasis (según el estándar)
  - [ ] Reglas de acotaciones (“dijo”, “preguntó”, etc.) y puntuación:
    - [ ] Cuándo usar “dijo” vs acciones (beats)
    - [ ] Cómo evitar adverbios y acotaciones redundantes
  - [ ] Claridad del hablante:
    - [ ] Regla práctica para evitar confusión (reafirmar quién habla cuando hay 3+ turnos)
  - [ ] Proporción recomendada diálogo vs acción (como criterio, no como número rígido)
  - [ ] Reglas de subtexto (qué NO decir explícitamente) + 2 tácticas prácticas (evasión, contradicción, omisión, etc.)
- [ ] Definir “marcadores de voz” por personaje (2–3 rasgos) en `01_Gestion/Estilo.md`:
  - [ ] Ritmo (frases cortas/largas)
  - [ ] Vocabulario (muletillas, nivel de formalidad)
  - [ ] Tendencia (preguntar/afirmar/ironizar/callar)
- [ ] Validación rápida (sin “chequear”, solo sentido común):
  - [ ] En una página con diálogo se entiende quién habla sin esfuerzo
  - [ ] El diálogo no repite información que el lector ya sabe
  - [ ] Hay fricción/subtexto cuando corresponde (no todo es “explicado”)
