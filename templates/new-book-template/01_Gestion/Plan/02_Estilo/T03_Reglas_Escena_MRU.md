# T03 Reglas de escena (MRU)

## Objetivo
Estandarizar cómo se escriben escenas para mantener claridad, ritmo y causalidad.

## Entradas
- [[01_Gestion/Plan/02_Estilo/T02_POV_y_Tiempo_Verbal|T02 POV y tiempo verbal]]

## Checklist
- [ ] Completar en `01_Gestion/Estilo.md` un protocolo MRU (Motivación → Reacción → Unidad de acción):
  - [ ] Motivación (externa): qué ocurre fuera del personaje y lo obliga a responder
  - [ ] Reacción (interna): sensación/pensamiento breve y concreto (sin explicar en abstracto)
  - [ ] Unidad de acción: decisión + acción (y diálogo si corresponde)
- [ ] Definir reglas prácticas en `01_Gestion/Estilo.md`:
  - [ ] Orden recomendado (no invertir sin motivo; si se invierte, aclarar por qué)
  - [ ] Tamaño de párrafos / alternancia acción-diálogo (criterio, no números rígidos)
  - [ ] Qué se considera “escena” vs “secuela”:
    - [ ] Escena: objetivo + conflicto + resultado (cambio)
    - [ ] Secuela: procesamiento + decisión + nuevo objetivo
  - [ ] Causalidad: cada beat debe poder conectarse con “por eso”
- [ ] Añadir un “template de escena” (copiable) en `01_Gestion/Estilo.md`:
  - [ ] Objetivo del POV
  - [ ] Obstáculo/fuerza opuesta
  - [ ] Cambio (resultado) + gancho hacia lo siguiente
- [ ] Añadir checklist rápido para cada escena (3–5 bullets) en `01_Gestion/Estilo.md`.
- [ ] Validación rápida (sin “chequear”, solo sentido común):
  - [ ] Se entiende qué quiere el personaje en la escena
  - [ ] La escena termina diferente a como empezó (hay cambio)
  - [ ] No hay “relleno”: cada bloque empuja decisión o conflicto

## Salidas (Definition of Done)
- Protocolo MRU definido en `01_Gestion/Estilo.md` y listo para usarse en drafts.
