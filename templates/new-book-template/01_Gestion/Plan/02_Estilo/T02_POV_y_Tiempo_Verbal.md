# T02 POV y tiempo verbal

## Objetivo
Fijar la cámara narrativa (POV + distancia + tiempo verbal) para evitar inconsistencias técnicas en el draft.

## Entradas
- [[01_Gestion/Plan/02_Estilo/T01_Voz_y_Tono|T01 Voz y tono]]

## Checklist
- [ ] Completar en `01_Gestion/Estilo.md` (sección “POV y tiempo verbal”):
  - [ ] POV:
    - [ ] 1ª / 3ª / múltiple; limitado u omnisciente
    - [ ] Si es múltiple: lista de POVs permitidos y criterio para elegir el POV de una escena
  - [ ] Distancia:
    - [ ] Deep POV / media / alta (definir la elegida)
    - [ ] Reglas prácticas (qué puede “saber” el narrador y qué no)
  - [ ] Tiempo verbal:
    - [ ] Pasado/presente (definir el elegido)
    - [ ] Excepciones permitidas (prólogo, epígrafes, cartas, recuerdos, etc.)
  - [ ] Cambios de POV (si aplica):
    - [ ] Cuándo se permiten (ej: solo cambio de escena/capítulo)
    - [ ] Cómo se marcan (separador, título de escena, etc.)
    - [ ] Qué está prohibido (head-hopping dentro de un mismo bloque)
- [ ] Escribir un mini-ejemplo (5–10 líneas) en `01_Gestion/Estilo.md` mostrando “cómo suena” el POV elegido (y, si aplica, un ejemplo de transición).
- [ ] Validación rápida (sin “chequear”, solo sentido común):
  - [ ] Se entiende siempre “en quién estamos”
  - [ ] El narrador no adelanta información fuera del POV elegido
  - [ ] El tiempo verbal no “baila” dentro del mismo bloque

## Salidas (Definition of Done)
- POV y tiempo verbal fijados en `01_Gestion/Estilo.md`.
