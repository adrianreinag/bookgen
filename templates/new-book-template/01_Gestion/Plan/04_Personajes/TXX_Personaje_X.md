# TXX Personaje X (plantilla)

Duplica esta tarea por personaje y renómbrala (ej: `T02_CHAR_Ana_Garcia.md`) o úsala como checklist al completar `CHAR_<slug>.md`.

## Objetivo
Crear una ficha de personaje completa y útil para escribir escenas (no solo biografía).

## Checklist mínimo (SOT)
- [ ] Archivo creado en `02_Biblia/Entidades/Personajes/` con nombre `CHAR_<slug>.md`
- [ ] Nombre canónico + alias (si aplica)
- [ ] Rol narrativo
- [ ] Want / Need
- [ ] Herida / mentira / verdad
- [ ] Motivación (por qué quiere eso)
- [ ] Miedo / límite
- [ ] Método (cómo consigue cosas)
- [ ] Relación con protagonista/antagonista
- [ ] Voz (2–3 rasgos de habla) y tics (si aplica)
- [ ] Aparición prevista (capítulos aproximados)

## Campos opcionales (recomendado)
- [ ] Historia previa (solo lo que impacta decisiones actuales)
- [ ] Recursos / habilidades / debilidades
- [ ] Secreto / giro potencial (si aplica)
- [ ] Arco por actos (inicio → medio → final)

## Hecho cuando
- La ficha permite escribir una escena del personaje sin inventar datos críticos “sobre la marcha”.
