# T01 Glosario core

## Objetivo
Definir el vocabulario canónico (términos) para evitar “drift” de nombres en drafts.

## Entradas
- [[01_Gestion/Plan/02_Estilo/T05_Sistema_de_Dialogo|T05 Sistema de diálogo]]

## Checklist
- [ ] Crear/actualizar el listado de términos canónicos:
  - [ ] Identificar 10–30 términos core (lugares, facciones, tecnología/magia, rangos, objetos, etc.)
  - [ ] Para cada término, crear una entidad en `02_Biblia/Entidades/Terminos/` con convención `TERM_<slug>.md` usando la plantilla `TERM_Template.md` de `00_Utiles/Vault Templates/`.
- [ ] En cada `TERM_*.md`, completar mínimo:
  - [ ] Nombre canónico
  - [ ] Definición (2–5 líneas)
  - [ ] Sinónimos/alias permitidos (si aplica)
  - [ ] Notas de uso (cuándo se menciona, con qué cuidado)
- [ ] Regla: a partir de ahora, todo draft usa el término canónico (o su alias autorizado).

## Salidas (Definition of Done)
- Al menos 10 entidades `TERM_*.md` creadas con definiciones mínimas.
