# T03 Geografía y lugares core

## Objetivo
Crear los escenarios principales como SOT para que cada escena tenga anclaje espacial y continuidad.

## Entradas
- [[01_Gestion/Plan/03_Worldbuilding/T02_Reglas_del_Mundo|T02 Reglas del mundo]]

## Checklist
- [ ] Listar los lugares indispensables para la historia (3–10).
- [ ] Crear entidades en `02_Biblia/Entidades/Lugares/` (convención `LOC_<slug>.md`).
- [ ] En cada `LOC_*.md`, completar mínimo:
  - [ ] Nombre canónico + alias (si aplica)
  - [ ] Descripción sensorial breve
  - [ ] Función narrativa (por qué existe)
  - [ ] Reglas/limitaciones del lugar (seguridad, acceso, clima, etc.)
  - [ ] Conexiones con otros lugares (distancia/tiempo)
- [ ] Identificar 1–3 lugares “core” y asegurarse de que aparecen en la escaleta más adelante.

## Salidas (Definition of Done)
- Al menos 3 entidades `LOC_*.md` creadas y listas para enlazarse desde capítulos.
