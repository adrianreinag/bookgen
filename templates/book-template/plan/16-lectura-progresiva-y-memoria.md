# 13. Lectura progresiva y memoria (por capitulo)

## Objetivo
Mantener un resumen vivo (CoD) y memoria estructurada sin cargar el manuscrito completo.

## Como actuar (procedimiento)
1. Lee como lector y detecta friccion (confusion, ritmo, lagunas).
2. Actualiza el resumen vivo para contexto JIT.
3. Registra eventos clave en memoria estructurada para continuidad.

## Entradas
- Draft del capitulo (ultima version).
- SOT actualizada.

## Salidas (Definition of Done)
- [[manuscript/context/story_so_far]] actualizado.
- `manuscript/context/memory_log.json` actualizado.
- Notas de lectura registradas si aparecieron problemas.

## Checklist paso a paso (por capitulo)
- [ ] Leer el capitulo de principio a fin sin editar.
- [ ] Anotar:
  - [ ] Confusiones (que no se entiende).
  - [ ] Caidas de ritmo.
  - [ ] Repeticiones.
  - [ ] Preguntas que el texto genera (buenas y malas).
- [ ] Detectar continuidad perceptiva:
  - [ ] Donde esta cada personaje al final.
  - [ ] Que sabe cada personaje (informacion).
  - [ ] Que quiere el protagonista ahora.
- [ ] Actualizar [[manuscript/context/story_so_far]]:
  - [ ] Resumen denso del capitulo.
  - [ ] Estado emocional del protagonista.
  - [ ] Consecuencia principal.
- [ ] Actualizar `manuscript/context/memory_log.json`:
  - [ ] Evento.
  - [ ] Capitulo.
  - [ ] Impacto (en trama, relaciones, mundo).
- [ ] Registrar en [[manuscript/feedback/critique_log]] si hay bloqueos reales.
