# 2. Guia de estilo

## Objetivo
Definir una voz consistente y reglas de escritura para que beats, drafts y revisiones no “deriven”.

## Como actuar (procedimiento)
1. Define primero la voz y el tono (macro).
2. Luego fija reglas operativas: MRU, deep POV, dialogo y sensorialidad.
3. Por ultimo, fija “listas negras” (muletillas, palabras prohibidas) para acelerar edicion.

- [[bible/seed]]

## Salidas (Definition of Done)
- [[bible/style_guide]] completo y usable como checklist editorial.

## Checklist paso a paso (en [[bible/style_guide]])
- [ ] Definir voz:
  - [ ] Lexico (formal/coloquial, tecnico, poetico).
  - [ ] Sintaxis (frases cortas/largas, cadencia).
  - [ ] Nivel de interioridad (deep POV).
- [ ] Definir tono:
  - [ ] Emocional (esperanzador, nihilista, ironico).
  - [ ] Moral (que juicios aparecen o se evitan).
- [ ] Definir referencias (2-5) y que se copia exactamente (ritmo, imagenes, humor).
- [ ] Definir ejemplos positivos (pequenas muestras o bullets con rasgos).
- [ ] Definir ejemplos negativos (lo que se evita y por que).
- [ ] Definir POV y tiempo verbal definitivos (que no cambian sin replanificar).
- [ ] Ritmo:
  - [ ] Longitud media de frases.
  - [ ] Longitud media de parrafos.
  - [ ] Regla de alternancia escena/secuela si aplica.
- [ ] MRU (regla operativa):
  - [ ] Motivacion externa -> reaccion interna -> accion -> dialogo.
  - [ ] Identificar ejemplos de errores tipicos (mezclar causa/efecto).
- [ ] Deep POV:
  - [ ] Lista de verbos filtro a evitar.
  - [ ] Como mostrar emociones (sensaciones/acciones).
- [ ] Lenguaje:
  - [ ] Registro (tu/usted, vulgaridad permitida, tecnicismos).
  - [ ] Palabras prohibidas (lista).
  - [ ] Muletillas a evitar (lista).
  - [ ] Regla de adverbios (limite o prohibicion).
- [ ] Dialogo:
  - [ ] Formato (comillas o guion largo) y consistencia.
  - [ ] Regla de subtexto (evitar “on-the-nose”).
  - [ ] Pautas de acotaciones (si se usan).
- [ ] Descripcion sensorial:
  - [ ] Minimo de sentidos por escena.
  - [ ] Prioridad de detalles concretos sobre adjetivos vagos.
- [ ] Consistencia:
  - [ ] Respetar glosario y capitalizacion.
  - [ ] Regla de nombres propios (como se escriben).
