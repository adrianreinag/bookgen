# 1. Semilla (seed)

## Objetivo
Convertir una idea en una premisa operable y verificable: promesa, conflicto, tema y restricciones.

## Como actuar (procedimiento)
1. Completa la seed sin escribir escenas: solo decisiones de historia.
2. Si hay huecos, conviertelos en preguntas (worldbuilding/research) en vez de improvisar.
3. Enlaza la seed con estilo y outline para que el grafo “amarre” la coherencia.

## Entradas
- Decisiones de [[plan/03-preparacion-del-proyecto]].

## Salidas (Definition of Done)
- [[bible/seed]] completo (sin [FILL]) y enlazado a estilo y estructura.
- Lista accionable de preguntas abiertas (worldbuilding + investigacion).

## Checklist paso a paso (en [[bible/seed]])
- [ ] Completar “Origen” (de donde sale la idea).
- [ ] Escribir logline (1 frase, sujeto + objetivo + obstaculo + stakes).
- [ ] Redactar premisa extendida en 4 parrafos (setup, confrontacion, crisis, resolucion).
- [ ] Definir tema central:
  - [ ] Mentira (creencia falsa del protagonista).
  - [ ] Verdad (leccion).
  - [ ] Pregunta moral.
- [ ] Definir protagonista:
  - [ ] Want (deseo externo).
  - [ ] Need (necesidad interna).
  - [ ] Herida o fantasma.
  - [ ] Arco en 1 linea.
- [ ] Definir antagonista o fuerza opuesta:
  - [ ] Objetivo.
  - [ ] Metodo.
  - [ ] Relacion con el protagonista.
- [ ] Definir genero y promesa:
  - [ ] Genero.
  - [ ] Subgenero.
  - [ ] Tropos obligatorios.
  - [ ] Tropos a evitar.
- [ ] Definir POV:
  - [ ] POV (1a/3a, unico/multiple).
  - [ ] Tiempo verbal.
  - [ ] Distancia narrativa.
- [ ] Definir longitud y publico:
  - [ ] Target word count.
  - [ ] Publico (perfil y expectativa).
- [ ] Elegir estructura macro (three act / save the cat / kisho ten ketsu) y anotar por que.
- [ ] Definir restricciones:
  - [ ] Limites de mundo.
  - [ ] Limites de tono (violencia, sexo, humor, etc).
  - [ ] No negociables de la premisa (lo que NO se cambia).
- [ ] Necesidades de investigacion:
  - [ ] Temas a verificar (bullets concretos).
  - [ ] Que datos bloquean estructura o escenas.
- [ ] Preguntas de worldbuilding a resolver (bullets concretos, no vagos).
- [ ] Verificar enlaces al final de la nota:
  - [ ] [[bible/style_guide]]
  - [ ] [[bible/timeline]]
  - [ ] [[structure/outline]]
