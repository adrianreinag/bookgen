# 14. Revision editorial (por capitulo)

## Objetivo
Convertir draft estable en capitulo final: macro (trama/ritmo) -> micro (linea).

## Como actuar (procedimiento)
1. Empieza por macro: claridad, escenas, consecuencias, arcos.
2. Luego voz: POV, tono, coherencia con style guide.
3. Luego micro: verbos filtro, adverbios, pasiva, repeticiones.
4. Exporta a `manuscript/final/` cuando el capitulo esta listo.

## Entradas
- Ultimo draft aprobado del capitulo.
- [[bible/style_guide]] y SOT.

## Salidas (Definition of Done)
- `chapters/chapter_##/final.md` listo.
- Notas de edicion / change log registrados.

## Checklist paso a paso (por capitulo)
- [ ] Macro:
  - [ ] El objetivo de cada escena es claro.
  - [ ] El conflicto tiene friccion real.
  - [ ] La consecuencia cambia el estado.
  - [ ] El capitulo cumple su funcion en el outline.
- [ ] Estructura de escenas:
  - [ ] Alterna escena/secuela si aplica.
  - [ ] No hay escenas “decorativas”.
- [ ] Voz:
  - [ ] Cumple [[bible/style_guide]] (POV, tiempo, distancia).
  - [ ] Dialogo consistente (formato y subtexto).
  - [ ] Sensorialidad suficiente.
- [ ] Micro:
  - [ ] Eliminar verbos filtro.
  - [ ] Reducir adverbios.
  - [ ] Reducir pasiva.
  - [ ] Evitar repeticion lexical.
- [ ] Generar archivo final:
  - [ ] Crear `chapters/chapter_##/final.md`.
  - [ ] Enlazar al draft de origen y beats (si aplica).
  - [ ] Escribir change log (bullets).
 - [ ] Pase final:
  - [ ] Buscar nombres inconsistentes (glosario).
  - [ ] Buscar verbos filtro frecuentes.
  - [ ] Verificar que el gancho final sigue funcionando.
