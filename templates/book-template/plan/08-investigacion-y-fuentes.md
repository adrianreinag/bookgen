# 5. Investigacion y fuentes

## Objetivo
Reducir riesgos (errores factuales, incoherencias tecnicas) antes de fijar estructura y escribir prosa.

## Como actuar (procedimiento)
1. Convierte dudas en preguntas verificables.
2. Prioriza lo que bloquea outline/beats (no lo accesorio).
3. Registra fuentes con “que valida” y “como se usara”.

## Entradas
- Preguntas de [[bible/seed]] y decisiones de worldbuilding/personajes.

## Salidas (Definition of Done)
- [[bible/research]] con temas priorizados y fuentes registradas con notas accionables.

## Checklist paso a paso (en [[bible/research]])
- [ ] Crear seccion “Temas a investigar” (lista larga, concreta).
- [ ] Para cada tema, definir:
  - [ ] Pregunta exacta.
  - [ ] Donde impacta (capitulo/escena/decision).
  - [ ] Si bloquea estructura (SI/NO).
- [ ] Priorizar:
  - [ ] Critico (bloquea beats).
  - [ ] Importante (mejora credibilidad).
  - [ ] Opcional (color).
- [ ] Buscar fuentes:
  - [ ] Fuente primaria o autoridad (cuando sea posible).
  - [ ] Fuente secundaria confiable (cuando no).
- [ ] Registrar cada fuente:
  - [ ] Enlace.
  - [ ] Fecha de acceso.
  - [ ] Nota de uso (que valida).
  - [ ] Riesgos/limitaciones (sesgo, contexto).
- [ ] Resumir hallazgos clave en bullets accionables.
- [ ] Marcar datos por verificar mas adelante (TODO verificacion).
- [ ] Mantener consistencia de citacion (APA/MLA/notas) segun la decision del proyecto.
 - [ ] Revisar que los hallazgos se reflejen en la SOT cuando corresponda:
  - [ ] Actualizar definiciones del mundo (si aplica).
  - [ ] Actualizar timeline (si cambia fechas/orden).
  - [ ] Actualizar glosario (terminos tecnicos).
